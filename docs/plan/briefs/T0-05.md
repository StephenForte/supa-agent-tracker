## Outcomes
1. /agents (src/pages/agents/AgentsPage.tsx) renders RunGrid with showProjectColumn, fed by listRuns(), listAgents() and listProjects() with no project argument. The h1 stays "All agents". Stop using the Placeholder wrapper.

3. Runs from archived projects are included, since history must stay reachable. They are distinguishable because the project column shows the project name and the project filter lists it. Don't hide them by default; that would make cancelled run_6 unreachable from this page.
4. View presets on the page: Active first (default; activity "all" with sort activity ascending), Live, Waiting for review, Completed. They map onto RunGrid's existing activity filter and sort through its controlled props, and they compose with the grid's other filters. The selected view is reflected in the URL as ?view=active|live|review|completed so a reviewer can link to it. An unknown value falls back to active. ?run=<id> also works here and expands that run, as on project detail.
5. Empty state (no runs at all) and no-match state come from RunGrid. Add nothing on top unless a view preset yields zero rows. In that case the message names the view and offers "Show all".

## The traps
1. Stale detection silently disappears. RunGrid computes staleness from props.projects; a run whose project is missing from that prop gets stale = false and no error. Pass every owned project, including archived ones, not just the projects that happen to have running work. Test it: on /agents, run_4 must show the Stale indicator and must never appear under the Live view.
2. Testing elapsed or stale with fake timers. src/data/runtime.ts subscribes systemClock with a real setInterval at import, so vi.useFakeTimers() installed inside a test never ticks useNow(). Assert live elapsed with a short real-time wait (about 2.5 s), or install fake timers before importing app modules.
3. Duplicating grid logic. Filtering, sorting, grouping, pagination, close and expansion all live in RunGrid and src/domain/runs/grid.ts. If you find yourself re-implementing any of it on the page, stop. If RunGrid genuinely can't do something you need, stop and report; you may not edit src/features/runs/** (T0-03-owned, merged).
