## The traps
1. Scope creep dressed as polish. Six workers' code is merged and reviewed. Rewriting a screen because you'd have built it differently throws away verified behaviour (see PLAN.md verification log) and creates an unreviewable diff. Fix defects with the smallest change at the right layer. Every behaviour change in a file owned by T0-02…T0-06 must keep that task's tests passing unmodified, unless the test encoded the defect you're fixing. In that case declare it under EXISTING CHECKS MODIFIED with before, after and why.
2. SPA fallback that only works locally. vite preview serves index.html for unknown paths, so direct-route reloads pass locally even with no Render rewrite. Your render.yaml rewrite is the only thing that makes them work on Render, and it can't be verified until a real deploy. Say so in RESIDUAL GAPS rather than claiming it works.
3. Fake timers vs systemClock (PLAN.md Known traps). Any test you add for elapsed or stale must use a short real-time wait or install fake timers before importing app modules.
